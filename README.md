# slyr

Free browser games you can play instantly. No downloads, no installs: pick a game and it opens.

**Play now: https://slyr.pages.dev/**

Also available at https://kalakaritzu.github.io/slyr/

## What it is

A fast, searchable shelf of 70+ browser games. Search by name or by keyword, filter by category (shooters, horror, platformers, strategy and more), and click a game to play it full screen.

## Games

Quake, Half-Life, GTA, Among Us, Minecraft (Eaglercraft), Hollow Knight, Stardew Valley, Balatro, Cuphead, ULTRAKILL and many more.
